# PEARL v2 - Constitutional Deterministic Agent Framework

A deterministic-first autonomous execution framework that prioritizes mechanical correctness, machine verification, event traceability, recoverability, and governance.

## Overview

PEARL v2 is built from the ground up as a framework where:

- Deterministic work is handled by mechanical scripts
- LLM reasoning is controlled and verified
- Runtime state is durable and recoverable
- Results are provable with evidence

## Core Technology Direction

- Rust Core
- SQLite/WAL
- Python/PowerShell Script Runtime
- Planner-Executor Architecture
- Event Ledger
